# 세법·하도급법 레퍼런스

국가법령정보센터 공식 자료로 세법·하도급법 실무 근거를 찾는 공개 사이트입니다. 기존 「안전레퍼런스」와 같은 화면 구성을 따릅니다.

- **세법**: 세무 인사이트 → 관계 법령(국세·지방세·관세 법률·시행령·시행규칙, 기본통칙) → 심판·판례 사례(조세심판원, 대법원) → 질의회신 Q&A(국세청·기재부·법제처 해석) → 실무 해설
- **하도급법**: 하도급 인사이트 → 관계 법령(하도급법, 상생협력법, 건설산업기본법, 공정위 고시·지침) → 공정위 의결·판례 → 질의회신 Q&A → 실무 해설
- 관리 메뉴: 개정 요약, 공식 자료실, 업데이트 이력

## 동작 방식
| 시각(평일, KST) | 담당 | 하는 일 |
|---|---|---|
| 08:30 | GitHub Actions `site.yml` | `collector/collect.mjs`로 법령 현행 버전·새 해석례·결정례 확인, 바뀐 자료만 `data/`에 커밋, 사이트 배포 |
| 09:00 | Claude 예약 작업 | `data/pending.json`에 변경이 있으면 [REVIEW.md](REVIEW.md) 절차로 개정 요약 작성, 커밋·배포, 이메일 알림. 변경이 없으면 아무것도 하지 않음 |

사이트는 GitHub Pages에서 제공되므로 개인 PC가 꺼져 있어도 동작합니다.

## 설정
- 저장소 Secret `LAW_API_OC`: 국가법령정보센터 Open API 인증값(OC). 코드나 사이트에 노출하지 않습니다.
- Settings → Pages → Source: **GitHub Actions**

## 개발
```sh
npm ci
npm run check          # 타입 검사
node build.mjs         # dist/ 생성
npm run test:e2e       # 테스트용 가짜 자료로 화면 점검(가짜 자료는 배포되지 않음)
node tests/smoke-real.mjs  # 실제 수집 자료로 주요 검색 점검(node build.mjs 후)
LAW_API_OC=... node collector/collect.mjs [--domain tax|subcon] [--only laws|rules|sources]
```

## 자료 원칙
- 원문이 없는 법령은 ‘본문 미수록’으로 표시하고, 검색은 법령명으로만 됩니다.
- 해석례·결정례는 당시 법령 기준임을 표시합니다.
- 실무 해설과 개정 요약은 수집한 원문을 근거로 작성하며, 근거 조문과 작성일을 함께 표시합니다. 사이트에서 유료 AI API를 호출하지 않습니다.
- 즐겨찾기와 메모는 방문자 브라우저에만 저장됩니다.
